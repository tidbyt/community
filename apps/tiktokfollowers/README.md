# TikTok Followers

Displays the current follower count for a public TikTok account.

![TikTok Followers preview](tiktok_followers.gif)

Enter a TikTok username in the Tidbyt app. No TikTok login or API key is
required. The profile response is cached for one hour.

The app reads the follower count embedded in TikTok's public profile page. If
TikTok changes or blocks the page, the app shows `NO DATA` instead of failing.

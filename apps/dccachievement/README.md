# Dungeon Crawler Carl Achievements Applet for Tidbyt

Displays a random achievement from the Dungeon Crawler Carl book series each day. Achievement data is gathered from the [Dungeon Crawler Carl fandom site](https://dungeon-crawler-carl.fandom.com/wiki/Achievement#All_Achievements).

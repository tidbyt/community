# NOAA Water Temp

NOAA Water Temp shows current water temperature from NOAA/NDBC station readings on Tidbyt.

Users can select a location to get nearby stations that are currently reporting water temperature, or enter a NOAA/NDBC station ID manually. The app supports Fahrenheit or Celsius, display modes, temp-reactive colors, a custom nickname, and optional marine details when NOAA reports them.

Data source: NOAA National Data Buoy Center latest observations.

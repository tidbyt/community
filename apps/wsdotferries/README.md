# WSDOT Ferries

Shows the next two departures for a Washington State Ferries (WSF)
terminal of your choice, along with a color-coded drive-up car space
bar for each sailing (green = plenty of space, yellow = filling up,
red = nearly full).

Uses the [WSDOT Ferries API](https://wsdot.wa.gov/traffic/api/). You'll
need a free access code - get one at https://wsdot.wa.gov/traffic/api/
and enter it in the app's settings.

Supports the WSF terminals that report live space availability:
Anacortes, Bainbridge Island, Bremerton, Clinton, Coupeville, Edmonds,
Friday Harbor, Kingston, Mukilteo, Orcas Island, Point Defiance, Port
Townsend, and Seattle.

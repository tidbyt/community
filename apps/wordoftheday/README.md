# Word Of The Day Applet for Tidbyt
---
Displays the Merriam-Webster Word Of The Day. The word and its definition come from the [Merriam-Webster WOTD RSS feed](https://www.merriam-webster.com/wotd/feed/rss2). The definition is the feed's abbreviated `shortdef`. Values are cached for 1 hour.
